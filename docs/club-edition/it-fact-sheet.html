Lineup Card: IT fact sheet

Facts you can check yourself. This sheet does not claim that the tool meets any club's IT policy. That is your call.

What it is

One HTML file, lineup-card.html, about 750 KB. Staff open it from disk in a web browser. The start screen has a "See a sample card" button that shows a finished card made from the fictional sample. With real files, it reads CSV exports from VALD ForceDecks, Catapult OpenField and a wellness form, shows a review screen where a person approves each flag, then shows a one-page card.

  • No install, no admin rights, no account, no server. No macros and no program files.
  • All code, styles, fonts and pictures are inside the file, plus a fictional sample roster for practice.
  • Checked in Google Chrome. Microsoft Edge uses the same engine but has not been checked yet. The check was on macOS, with the file opened from disk.

Network

The file carries this Content-Security-Policy in its first lines:

default-src 'none'; script-src [sha256 hashes of its two scripts]; style-src 'unsafe-inline'; font-src data:; img-src data: blob:; connect-src data:; base-uri 'none'; form-action 'none'

It allows no web address at all. Only the two scripts whose exact text matches a hash can run. Fonts and pictures may come only from data: and blob:, which means content already inside the file or made in memory. The policy blocks the page from loading or sending data over the network, and no form can be sent anywhere. It does not stop a user clicking a link.

How to check: open the file, press F12, open the Network tab and reload. Only the file itself and data: or blob: items are listed. Use the app, and the list stays the same. To see the policy, right-click the page and choose View page source.

Data

  • Dropped CSV files are read into browser memory only. They are not saved, and they are gone when the tab closes.
  • Saved reviews go in that browser's local storage, under keys that start lineupcard:review: plus the club name (URL-encoded) and date. A review holds the reviewer's name, today's player IDs, each flag decision with its note, and the approval time.
  • To delete them: click "Forget saved reviews on this computer" on the start screen, or clear the browser's site data. In Chrome, files opened from disk share one local storage area, so another HTML file opened from disk in the same browser profile could read saved reviews. For a shared laptop, run the file in its own browser profile.
  • Files it can make, only when a user clicks: "Export review" saves a JSON file, "Save as image" saves a PNG, and "Copy for group text" puts text on the clipboard. "Save PDF" (or Ctrl+P) opens the browser's own print window, where the user can save the card as a one-page PDF.
  • Nothing is uploaded. There is no tracking and no analytics.

AI

None inside. The file makes no calls to any AI service, and its policy would block them. Flags come from fixed math that staff review and approve.

An optional prompt guide (COPILOT-CHATGPT-PROMPTS.md) suggests text staff could paste into the club's approved Copilot or ChatGPT, using only the approved card text.

Limits

  • A coaching aid. Not a diagnosis and not an injury predictor. Coaches and medical staff decide who plays.
  • Catapult times are read as US Central time (America/Chicago) for every club. There is no setting for it.
  • Not tested inside any club's network or with a club's real exports yet. The column names are modeled on public examples of VALD and Catapult exports.
  • Not a club product. Built by Mauro Castillo as a portfolio example.
